# 黒ナンバー書類自動生成アプリ

AmazonFlex・Uberなどで軽自動車を使って配送業を始める事業者向けに、
必要項目を入力するだけで行政提出書類を自動生成するWebアプリです。

## 🚀 デモURL（共有可能）

**👉 https://mvp-three-ivory.vercel.app**

> Phase 1 MVP：氏名を入力すると5種類の届出書フォーマットに自動記入 + PDF出力デモ

## 生成対象書類

| # | 書類名 | 提出先 |
|---|---|---|
| 1 | 貨物軽自動車運送事業経営届出書 | 管轄運輸支局 |
| 2 | 運賃料金設定届出書 | 管轄運輸支局 |
| 3 | 運賃料金表 | 管轄運輸支局 |
| 4 | 事業用自動車等連絡書 | 運輸支局→軽自動車検査協会 |
| 5 | 貨物軽自動車安全管理者選任届出書 | 管轄運輸支局（**2025年4月義務化**） |

## ローカル開発

```bash
cd mvp
npm install
npm run dev
# → http://localhost:3000
```

## 技術スタック

- **フロントエンド：** Next.js 14 + Tailwind CSS + TypeScript
- **PDF生成：** pdf-lib
- **ホスティング：** Vercel
