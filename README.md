# 黒ナンバー書類自動生成アプリ

AmazonFlex・Uberなどで軽自動車を使って配送業を始める事業者向けに、
必要項目を入力するだけで行政提出書類を自動生成するWebアプリです。

## 生成対象書類

1. 貨物軽自動車運送事業経営届出書
2. 運賃料金設定届出書
3. 運賃料金表
4. 事業用自動車等連絡書
5. 貨物軽自動車安全管理者選任届出書（2025年4月義務化対応）
