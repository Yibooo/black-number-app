# 黒ナンバー書類自動生成アプリ 要件定義書

**作成日：** 2025年
**バージョン：** 1.0
**対象ユーザー：** AmazonFlex・Uber等で軽自動車配送業を始める個人事業主・法人

---

## 1. プロジェクト概要

### 1.1 目的
貨物軽自動車運送事業（黒ナンバー）の開業に必要な行政書類の作成を、
スマホ・PCからの最小限の入力で完結させる。PDF/Excel形式で出力し、
そのまま印刷・提出可能な状態にする。

### 1.2 背景
- 届出書類は複数あり、同じ情報を繰り返し記入する手間がある
- 2025年4月に安全管理者選任義務が追加され、対応書類が増加した
- AmazonFlex・Uber等の配送プラットフォームの普及で開業者が急増している

## 4. 機能要件

### 4.1 フォーム入力機能
- **ステップ形式UI：** カテゴリごとに画面を分割（進捗バー表示）
- **郵便番号自動補完：** 郵便番号入力で住所を自動入力
- **自動コピー機能：** 自宅兼用・営業所併設チェックで住所を自動転記
- **バリデーション：** リアルタイムエラー表示
- **警告表示：** 車検証名義が届出者と異なる場合、住民票必要の旨を表示
- **日付チェック：** 講習修了日 < 選任日、開始日 >= 提出日

### 4.2 車検証OCR機能（Phase 2）
- スマホカメラ撮影 or 画像アップロードで車検証から自動読み取り
- 抽出項目：車台番号、登録番号、車名、型式、所有者名
- 読み取り確認画面で修正可能

### 4.3 PDF生成機能
- 行政指定フォーマット（A4）に入力データを正確な座標に配置
- 各書類を個別PDFまたは一括ZIPで出力
- 押印欄スペースを確保（押印廃止地域でも印刷後に押印可能なレイアウト）
- 提出チェックリストPDFを同時生成

### 4.4 Excel出力機能
- 書類ごとにシートを分けて1ファイルに出力
- セルへのデータ配置（行政フォーマットに準拠）

### 4.5 運賃テンプレート機能
| テンプレート名 | 想定用途 |
|---|---|
| AmazonFlex向け標準 | Amazon配送パートナー |
| 軽貨物スポット向け | 単発配送・マッチングアプリ |
| 定期便向け | 固定取引先との定期契約 |
| カスタム | 手動入力 |

## 5. 非機能要件

### 5.1 対応デバイス
- PC（Chrome, Firefox, Safari, Edge 最新版）
- スマートフォン（iOS Safari, Android Chrome）
- レスポンシブデザイン対応

### 5.2 セキュリティ
- 入力データはセッション内のみ保持（サーバーへの個人情報保存なし）
- HTTPS必須
- 将来的なデータ保存機能追加時はユーザー認証必須

### 5.3 パフォーマンス
- PDF生成：10秒以内
- 初期表示：3秒以内

## 6. 開発フェーズ

### Phase 1（MVP）- 本リポジトリの現状
- 名前入力 → 届出書フォーマットへの記入デモ
- フロントエンドのみ（Next.js + Tailwind CSS）

### Phase 2
- 全入力項目対応
- PDF生成エンジン実装（pdf-lib）
- Excel出力実装（SheetJS/ExcelJS）
- 全5書類の出力対応

### Phase 3
- 車検証OCR機能（Google Vision API）
- 郵便番号自動補完（zipcloud API）
- 運賃テンプレート機能

### Phase 4
- ユーザー認証・入力データ保存
- 変更届・更新書類対応
- 法改正時の書類フォーマット自動更新

---

## 7. 注意事項・制約

1. **書類フォーマットの最新版確認：** 国土交通省の様式は改訂される場合があり、定期的な更新が必要
2. **地域差への対応：** 管轄運輸支局によって書式・押印要否が異なる場合がある
3. **2025年4月法改正：** 安全管理者選任届（書類5）は2025年4月以降の新規開業者に即時必要
4. **法的免責事項：** 本アプリは書類作成補助ツールであり、行政書士への相談を推奨する旨を表示する
