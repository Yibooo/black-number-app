# ① 貨物軽自動車運送事業経営届出書

| 項目 | 内容 |
|---|---|
| 様式 | 様式第1号（貨物自動車運送事業法 第36条第1項） |
| 提出先 | 管轄の運輸支局（地方運輸局長/運輸支局長 宛） |
| 部数 | 正本・控（受付印をもらう用）の **2部** が一般的 |
| 役割 | 黒ナンバー事業を始めることの本体となる届出書 |

> 見本画像: [images/01-keiei-todoke.svg](images/01-keiei-todoke.svg)

---

## 記入欄の定義

| 欄 | 何を書くか | 記入例 | 注意点 | 対応する入力項目 |
|---|---|---|---|---|
| 届出年月日 | 提出する日（和暦） | 令和8年6月1日 | 提出日。先付け可だが事業開始日との整合に注意 | `submitDate` |
| 宛名 | 「○○運輸支局長 殿」 | 東京運輸支局長　殿 | 管轄都道府県から自動補完 | `prefecture` |
| 届出者 住所 | 届出者の住所 | 東京都渋谷区渋谷1-2-3 渋谷ハイツ101 | 郵便番号は別記または併記 | `postalCode` `address` |
| 届出者 氏名/名称 | 個人=氏名／法人=名称＋代表者氏名 | 山田 太郎 | 押印欄は廃止傾向だが空欄スペース確保 | `name` `representativeName` |
| 氏名又は名称 | 事業者の氏名・名称（本文表内） | 山田 太郎 | 届出者と同一 | `name` |
| 営業所の名称及び位置 | 営業所名と所在地 | 山田運送／東京都渋谷区渋谷1-2-3 | 自宅兼用なら住所と同一 | `officeName` `officeAddress` |
| 事業用自動車の種別及び数 | 「軽自動車（貨物）○両」 | 軽自動車　1両 | 軽貨物のみ。台数は車両数 | `vehicles.length` |
| 自動車車庫の位置及び収容能力 | 車庫所在地と収容台数 | 東京都渋谷区渋谷1-2-3／1両 | 営業所併設可。原則直線2km以内 | `garageAddress` `garageCapacity` |
| 事業の開始予定日 | 開業予定日（和暦） | 令和8年6月15日 | 提出日以降 | `businessStartDate` |
| 運送約款 | 標準約款使用の有無 | ☑ 標準貨物軽自動車運送約款を使用 | 標準約款使用なら約款添付不要 | （固定: 標準約款使用） |

## よくあるミス・差戻し理由

- **車庫が営業所から直線2kmを超える** … 車庫は営業所に併設または近接が原則
- **事業開始予定日が提出日より前** … 整合性エラー
- **車検証の名義が届出者と異なる** … 使用権原を示す書類（賃貸借契約・使用承諾等）が別途必要
- **軽自動車以外を記載** … 本事業は軽貨物（軽自動車）のみ
