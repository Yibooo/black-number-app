# ③ 運賃料金表

| 項目 | 内容 |
|---|---|
| 様式 | 任意様式（②運賃料金設定届出書の別紙） |
| 提出先 | 管轄の運輸支局（②と一体で提出） |
| 役割 | 実際の運賃・料金の金額を一覧で示す表 |

> 見本画像: [images/03-unchin-hyo.svg](images/03-unchin-hyo.svg)

---

## 記入欄の定義

| 欄 | 何を書くか | 記入例 | 注意点 | 対応する入力項目 |
|---|---|---|---|---|
| 事業者名 | 届出者の氏名・名称 | 山田 太郎 | ①②と同一 | `name` |
| 距離制 初乗り | 初乗り区間と金額 | 2kmまで 800円 | テンプレートで自動入力 | `fareSettings.distanceFareBase` |
| 距離制 加算 | 加算単位と金額 | 以降1kmごと 200円 | 同上 | `fareSettings.distanceFareIncrement` |
| 時間制 運賃 | 1時間あたり | 1時間 4,000円 | 同上 | `fareSettings.timeFare` |
| 待機料金 | 待機の単位と金額 | 30分ごと 500円 | 任意 | `fareSettings.waitingFee` |

### 運賃テンプレート（Phase B/C で選択）

| テンプレート | 初乗り | 加算 | 時間制 | 待機 |
|---|---|---|---|---|
| AmazonFlex向け標準 | 2kmまで 800円 | 1kmごと 200円 | 1時間 4,000円 | 30分 500円 |
| 軽貨物スポット向け | 2kmまで 700円 | 1kmごと 180円 | 1時間 3,500円 | 30分 400円 |
| 定期便向け | 別途協議 | 別途協議 | 1時間 3,800円 | 30分 450円 |
| カスタム | 手動入力 | 手動入力 | 手動入力 | 手動入力 |

> 上記金額は **例示** です。実際の運賃は事業者が自由に設定できます。

## 記入例（完成イメージ）

```
                  運　賃　料　金　表
               （貨物軽自動車運送事業）

                              事業者名：山田 太郎

 ┌──────────────── 距離制運賃 ────────────────┐
 │ 区　間              │ 運　賃            │ 備考 │
 ├─────────────────────┼───────────────────┼──────┤
 │ 初乗り（2kmまで）   │ 800円             │  —   │
 │ 2km超 1kmごと       │ 200円加算         │  —   │
 └─────────────────────┴───────────────────┴──────┘

 ┌──────────── 時間制運賃・料金 ────────────┐
 │ 時間制運賃（1時間）        │ 4,000円        │
 │ 待機料金（30分ごと）       │ 500円          │
 └────────────────────────────┴────────────────┘
```

## よくあるミス・差戻し理由

- **②と単位・金額が食い違う** … ②は「別紙のとおり」とし、金額は③に一本化
- **事業者名の記載漏れ** … 誰の運賃表か特定できるよう氏名/名称を必ず記載
