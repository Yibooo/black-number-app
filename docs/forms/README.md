# 黒ナンバー届出書類 記入仕様・記入例（書き方見本）

このディレクトリは、本アプリが自動生成する各書類について
**「どの欄に・何を・どう書くか」** を定義した *正解の仕様書* です。
フォーム実装（Phase B）とPDF出力（Phase C）は、すべてここの定義に従います。

> ⚠️ **重要な前提**
> - 様式・記載要領は **管轄の運輸支局や法改正により異なる/変わる** ことがあります。
>   実装・提出前に必ず国土交通省および管轄運輸支局の **公式最新様式** を確認してください。
> - 本アプリは **書類作成補助ツール** であり、行政書士による法的助言の代替ではありません。
> - 日付は原則 **和暦（令和）** で記入します。

## 3. 自動記入の凡例（見本画像・プレビュー共通）

- **青字・下線** … フォーム入力値から **自動記入** される箇所
- グレー文字 … 運輸支局・検査協会が **窓口で記入/押印** する箇所（ユーザーは空欄でよい）
- 「□」 … チェックボックス（該当項目にレ点）

## 4. 入力データ項目との対応

各mdの「対応する入力データ項目」列は、`types/form-data.ts`（技術設計書 4章）の
フィールド名に対応します。フォーム1項目が複数書類の複数欄に展開される点に注意。

| 入力項目 | 反映される書類 |
|---|---|
| 氏名・住所・電話 | ①②④⑤ の届出者欄 |
| 営業所・車庫 | ① |
| 車両情報 | ④ |
| 安全管理者情報 | ⑤ |
| 運賃設定 | ②③ |
| 管轄都道府県 | ①②⑤ の宛名（○○運輸支局長 殿） |
| 提出日・事業開始日 | ①（和暦） |

## 5. Phase C 実装メモ（公式様式の取得・座標配置）

「所定様式に正式記入」を実現するには、**国土交通省／地方運輸局が配布する空欄の公式様式PDF**を
テンプレートとして取得し、各欄のピクセル座標に `pdf-lib` でテキストを配置する必要がある。

- **実物様式の特徴（記入見本の調査結果）**
  - ④事業用自動車等連絡書などは **「1文字1マス」のマス目レイアウト**。車台番号・登録番号は枠割りに合わせて1文字ずつ配置する
  - 届出者欄・本文表の位置は様式により固定。和暦（令和）で記入
  - 押印欄は廃止傾向だがスペースは残す
- **取得元（要・最新確認）**: 国土交通省 各地方運輸局サイトの様式ダウンロードページ。`mvp/public/templates/` に配置予定
- **参考にした記入見本**: 「黒ナンバー取得資料 書き方 例」で出る各種ガイド（RAISEON / freee / 行政書士事務所 等）の記入済みサンプル。サンプル名は田中貨太郎・佐藤太郎などが多い（本リポジトリは山田太郎で統一）
- **注意**: Web検索のサムネイル画像は低解像度のため座標取得には使えない。必ず公式の空欄様式PDFを基準にすること
