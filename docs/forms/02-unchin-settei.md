# ② 運賃料金設定届出書

| 項目 | 内容 |
|---|---|
| 様式 | 様式第3号（貨物自動車運送事業法 第36条第2項） |
| 提出先 | 管轄の運輸支局 |
| 部数 | 正・控の **2部** が一般的 |
| 役割 | 自社の運賃・料金を設定したことの届出。実際の金額は③運賃料金表で示す |

> 見本画像: [images/02-unchin-settei.svg](images/02-unchin-settei.svg)

---

## 記入欄の定義

| 欄 | 何を書くか | 記入例 | 注意点 | 対応する入力項目 |
|---|---|---|---|---|
| 届出年月日 | 提出日（和暦） | 令和8年6月1日 | ①と同日が自然 | `submitDate` |
| 宛名 | ○○運輸支局長 殿 | 東京運輸支局長　殿 | 管轄から自動補完 | `prefecture` |
| 届出者 住所 | 届出者住所 | 東京都渋谷区渋谷1-2-3 渋谷ハイツ101 | ①と同一 | `postalCode` `address` |
| 届出者 氏名/名称 | 氏名または法人名 | 山田 太郎 | ①と同一 | `name` |
| 設定する運賃・料金 | 「別紙運賃料金表のとおり」 | 別紙のとおり | 金額本体は③に記載 | （固定文＋③参照） |
| 実施（適用）年月日 | 運賃の適用開始日 | 令和8年6月15日 | 事業開始予定日と合わせるのが自然 | `businessStartDate` |

---

## 記入例（完成イメージ）

```
                                              様式第3号
            運賃料金設定届出書

                                      令和8年6月1日

 東京運輸支局長　殿

                          届出者
                          住所  東京都渋谷区渋谷1-2-3 渋谷ハイツ101
                          氏名  山田 太郎              （印）

 貨物軽自動車運送事業の運賃及び料金を下記のとおり設定したので、
 貨物自動車運送事業法第36条第2項の規定により届け出ます。

                  記

   1. 設定する運賃及び料金 … 別紙「運賃料金表」のとおり
   2. 実施年月日           … 令和8年6月15日
```

---

## よくあるミス・差戻し理由

- **③運賃料金表を添付し忘れる** … ②と③はセットで提出
- **適用開始日が事業開始予定日と矛盾** … 整合をとる
- **金額を②本文に細かく書いてしまう** … 金額は③にまとめ、②は「別紙のとおり」が定石
