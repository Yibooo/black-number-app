# ④ 事業用自動車等連絡書

| 項目 | 内容 |
|---|---|
| 様式 | 事業用自動車等連絡書 |
| 提出先 | まず管轄運輸支局 → **受付印（確認印）** をもらい → 軽自動車検査協会へ持参 |
| 役割 | 黄ナンバー（自家用）を黒ナンバー（事業用）へ変更するための“通行手形”。**この書類がないとナンバー変更ができない** |

> 見本画像: [images/04-renrakusho.svg](images/04-renrakusho.svg)

---

## 記入欄の定義

| 欄 | 何を書くか | 記入例 | 注意点 | 対応する入力項目 |
|---|---|---|---|---|
| 作成年月日 | 提出日 | 令和8年6月1日 | ①〜③と同日 | `submitDate` |
| 番号 | 運輸支局が付番 | （空欄） | **窓口記入** | — |
| 事業者 氏名・名称 | 届出者 | 山田 太郎 | ①と同一 | `name` |
| 事業者 住所 | 届出者住所 | 東京都渋谷区渋谷1-2-3 | ①と同一 | `address` |
| 使用の本拠の位置 | 営業所所在地 | 東京都渋谷区渋谷1-2-3 | 営業所と同じが通常 | `officeAddress` |
| 車名・型式 | 車検証の車名/型式 | スズキ／EBD-DA17V | 車検証どおり | `vehicles[].vehicleName` `vehicles[].model` |
| 車台番号 | 車検証の車台番号 | DA17V-1234567 | 車検証どおり | `vehicles[].chassisNumber` |
| 自動車登録番号 | 現在のナンバー | 品川 480 あ 12-34 | 変更前（黄）ナンバー | `vehicles[].plateNumber` |
| 用途区分 | 「貨物」 | 貨物 | 固定 | （固定: 貨物） |
| 異動事項 | 「新規（自家用→事業用）」 | 自家用 → 事業用 | 新規届出 | （固定: 新規） |
| 運輸支局 受付印 | 確認印欄 | （空欄） | **窓口で押印** | — |

## よくあるミス・差戻し理由

- **車台番号・登録番号が車検証と1文字でも違う** … 検査協会で受理されない
- **受付印をもらう前に検査協会へ行ってしまう** … 必ず運輸支局 → 検査協会の順
- **複数台あるのに1枚にまとめる** … 原則 **1台につき1枚**（台数分作成）
